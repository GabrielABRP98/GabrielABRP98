# 🚀 Projetos em destaque

## 🤖 Kora — Plataforma Multiunidade de Atendimento e Automação com IA

Plataforma de atendimento empresarial desenvolvida em **n8n**, estruturada como um orquestrador multiagente para diferentes unidades de negócio.

A solução interpreta a necessidade atual do cliente, direciona a conversa para agentes especializados, mantém contexto entre interações e controla a transição entre atendimento automatizado e atendimento humano.

**Principais recursos:**

- Arquitetura multiagente e multiunidade
- Roteamento inteligente entre áreas de negócio
- Processamento de texto, áudio e imagem
- Memória e histórico de atendimento
- Persistência com Supabase, PostgreSQL e Redis
- Handoff controlado para atendimento humano
- Pausa e reativação automática da IA
- Integrações via webhooks e APIs
- Ambiente preparado com Docker

**Tecnologias:**

`n8n` `OpenAI` `Supabase` `PostgreSQL` `Redis` `Docker` `Webhooks` `APIs REST`

## 📊 Dashboard Comercial — Power BI

Projeto de **Business Intelligence** desenvolvido para análise de desempenho comercial, acompanhamento de indicadores financeiros e identificação de padrões de vendas.

O dashboard utiliza dados simulados em um modelo dimensional no formato **esquema estrela**, com análises de clientes, produtos, vendedores, canais, regiões e transações comerciais.

**Principais recursos:**

- Receita bruta e líquida
- Lucro total e margem de lucro
- Ticket médio
- Total de vendas e clientes
- Ranking de vendedores
- Análise por produto, categoria, região e canal
- Análises temporais
- Segmentações e filtros interativos
- Modelagem dimensional
- Medidas DAX
- Transformações com Power Query
- Geração da base de dados com Python

**Tecnologias:**

`Power BI` `Power Query` `DAX` `Python` `CSV` `Modelagem Dimensional` `Star Schema`

## 🤟 LIB_ACCESS — Reconhecimento de Libras

Protótipo de acessibilidade em desenvolvimento, criado para demonstrar a aplicação básica de **visão computacional** e **Machine Learning** no reconhecimento de sinais da Língua Brasileira de Sinais.

O objetivo do projeto não é apresentar uma solução completa de tradução de Libras, mas demonstrar a lógica fundamental de um pipeline de reconhecimento: captura de imagem, detecção das mãos, extração de características, preparação dos dados e classificação dos sinais.

**Funcionalidades do protótipo:**

- Captura de vídeo em tempo real
- Detecção e rastreamento das mãos
- Extração de pontos de referência
- Preparação de dados para treinamento
- Classificação básica de sinais
- Exibição do resultado reconhecido

**Tecnologias:**

`Python` `OpenCV` `MediaPipe` `Scikit-learn` `Machine Learning` `Visão Computacional`

> Projeto em desenvolvimento. O repositório será publicado após a consolidação da versão de demonstração.
